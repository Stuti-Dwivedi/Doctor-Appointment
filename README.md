# 🩺 Doctor Appointment System

A full-stack Doctor Appointment web application built with **React.js, Node.js, Express.js, and MongoDB**.

This project provides a simple interface for users to register, log in, book appointments, view their appointments, and edit appointment details. The project is divided into a React-based frontend and a Node.js/Express-based backend.

---

## 📌 About the Project

I built this project to understand how a complete full-stack application works by connecting a React frontend with a backend API and database.

The project is divided into two main parts:

- **doctor-ui** → React.js frontend
- **doctor-api** → Node.js + Express.js backend

The frontend is responsible for the user interface and application pages, while the backend handles API requests, routing, controllers, database connection, and user-related data.

The application follows a simple flow:

```text
User
  ↓
React Frontend
  ↓
